# 六爻排盘（liuyao）

移动端优先的六爻纳甲排盘 H5 应用：在线起卦（摇一摇 / 长按甩出 / 点击）、专业排盘（纳甲·六亲·六神·世应·旬空·月破·四柱）、《周易》卦爻辞原文 + 原创古注与现代解读。单文件、零后端、离线可用。

**在线访问**：部署到 GitHub Pages 后为 `https://<用户名>.github.io/<仓库名>/`

## 仓库结构

```
index.html                  ← 网站成品(构建产物, Pages 入口, 引擎与数据已内联)
apps/web/app_source.html    ← 界面源码(构建前模板)
packages/hexagram-core/     ← 排盘引擎源码(TypeScript 纯函数)
data/                       ← 数据工程: 建表/种子SQL、数据生成器、快照导出、内容裁定台账
tests/                      ← 78条卦理黄金用例(fixture) + 测试方独立生成器 + 运行器
docs/                       ← 全套工程文档(产品/交互/架构/测试/数据/内容/上线检查)
```

## 质量基线（提交前必须保持全绿）

| 项 | 标准 |
|---|---|
| 卦理黄金用例 | 78/78 通过（含节气交接、23点换日边界） |
| 随机分布 | 10万次卡方检验通过，各爻象偏差 <1% |
| 经文内容 | 双源全量比对闭环（裁定台账 data/t6_adjudication.json） |
| 注解内容 | 全部原创；断语词扫描零命中；与参考书籍 10 字片段查重为 0 |

## 核心口径（动数据前必读）

- 日柱 **23 点换日**（晚子时归次日）；四柱按**北京时间**推算
- 月柱以**节气**分界，节气数据为寿星天文历法 1950–2050 分钟级（双库交叉验证）
- 掷爻使用 `crypto.getRandomValues`，三枚铜钱独立等概率；**手势参数不进入随机函数**
- 一切卦理数据（卦宫/世应/纳甲/经文）只能改 `data/` 的生成器或种子 SQL 再重导快照，**禁止手改 JSON 或在代码中硬编码**
