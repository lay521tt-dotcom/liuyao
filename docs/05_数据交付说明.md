## 数据生产方式声明（重要）
卦宫、世应、纳甲等 458 行卦理数据**不是手抄的**，而是由 generate.py 按八宫纳甲定式规则程序推演生成，
生成过程内置权威断言（八宫各 8 卦全表比对、乾坤姤明夷等关键纳甲、甲子旬空戌亥等），任一断言失败即拒绝出数。
修改数据必须改规则脚本重新生成，禁止直接改 SQL —— 保证数据永远可追溯、可复算。

1. **节气表 solar_term 为空表**：干支历的月柱分界依赖 1950–2050 精确到分钟的节气时刻。
   此数据必须从权威历表（紫金山天文台《中国天文年历》体系的公开历表数据）导入，不可用简化公式估算。
   负责人：数据工程师；阻塞对象：ganzhi-calendar 模块的黄金用例（M2 前必须就位）。
2. **卦爻辞内容**：剩余 62 卦卦辞 + 377 条爻辞原文录入及原创注解撰写，按 seed_text_sample.sql 格式补齐。
   原文须逐条与通行本核对；注解遵守产品文档 5.7 写作规范（60–150字、不下吉凶断语）。
   与 UI 开发并行，M3 前完成，上线前全量校对（产品文档 7.3）。
3. export-snapshot 脚本（DB→前端JSON快照）随 M2 排盘引擎联调时交付。
