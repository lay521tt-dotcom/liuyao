# 六爻占卜网站 页面交互说明书 V1.0

> 上游文档：《产品说明书 V1.0》（已含甲方修订：23点换日、手势起卦）
> 适用读者：架构师、前端程序员、测试工程师
> 本文档定义页面结构与交互行为，不定义技术实现方式

---

## 1. 设计基调

- 视觉方向：东方水墨/宣纸质感，主色：墨黑 + 宣纸米白 + 朱砂红点缀；阳爻阴爻用传统黑色爻画
- 字体：标题可用宋体/楷体类衬线，正文无衬线保证小屏可读
- 基准设计宽度 375px，单手拇指可达区放置主操作按钮（屏幕下半部）
- 动效原则：起卦阶段允许有仪式感动效（铜钱旋转下落），结果页禁止干扰阅读的动效

## 2. 页面清单与信息架构

```
首页(P1)
 ├─ 摇卦页(P2)  ← 核心页面
 │    └─ 排盘结果页(P4)
 ├─ 手动录入页(P3)
 │    └─ 排盘结果页(P4)
 ├─ 历史记录页(P5) → 排盘结果页(P4只读态)
 └─ 关于与免责声明页(P6)
```

底部不做全局导航栏（流程型产品），各页面左上角统一返回按钮。

---

## 3. 各页面规格

### P1 首页
布局自上而下：
1. 品牌区：站名 + 一句话说明（高度约 25%）
2. 占问输入区：分类标签横滑选择（事业/感情/财运/健康/出行/其他）+ 选填文本框「所占何事」（单行，可展开）
3. 主按钮「摇卦起卦」（大，朱砂红）
4. 次按钮「手动录入卦象」（描边样式）
5. 页脚：历史记录入口、关于/免责声明入口（小字）

交互：占问可留空直接起卦；文本框聚焦时页面上推避免键盘遮挡。

### P2 摇卦页（核心交互，详见第 4 章手势规范）
布局：
1. 顶部：进度指示「第 N 爻 / 共六爻」+ 已成爻象自下而上堆叠显示（迷你卦象区，初爻在最下）
2. 中部：三枚铜钱视觉区（默认静置态）
3. 底部：手势引导文案区 + 兜底按钮「点击摇卦」

状态机（每一爻一轮）：
```
待摇 → 蓄力/摇晃中 → 掷出动效(0.8~1.2s) → 落定显示三枚正反
     → 本爻结果浮层(老阳/少阳/少阴/老阴 + 爻画飞入迷你卦象区, 0.6s)
     → 第N+1爻待摇 …… 六爻完成 → 自动跳转P4(过渡动效≤1s, 可跳过)
```
- 动爻落定时铜钱区出现朱砂色「动」字标记，并伴随震动反馈（仅支持的设备，见 4.5）
- 摇卦中途退出需二次确认弹窗「本卦尚未完成，确定放弃？」

### P3 手动录入页
1. 顶部说明图：铜钱字/背约定图示（产品文档 5.1 要求）
2. 六行录入区，自下而上排列（初爻在最下，与卦象方向一致），每行四个选项钮：老阴 / 少阳 / 少阴 / 老阳（同时标注背面数 0/1/2/3 帮助对照）
3. 起卦时间：默认当前时间，可修改（影响干支/六神/旬空，时间控件需支持选择日期+时辰）
4. 主按钮「排盘」：六爻未录全时置灰，点击置灰按钮提示缺哪几爻

### P4 排盘结果页（信息密度最高页面）
移动端纵向分区，卡片式：
1. 卦头区（常驻）：本卦卦名卦象 →（有动爻时）箭头 → 变卦卦名卦象；占问事项；起卦时间（公历+干支四柱）；旬空、月建、日辰
2. 卦盘区（常驻，本页核心）：专业六爻表格，每行一爻自上而下显示：六神 | 六亲+纳甲干支五行 | 爻象（动爻带标记与变爻指向）| 世/应标记。要求 375px 宽度内完整呈现不横向滚动，字号不小于 12px，必要时纳甲信息换行
3. 原文注解区（手风琴折叠，默认展开第一项）：本卦卦辞+注解 / 各动爻爻辞+注解（多个动爻按爻位排列）/ 变卦卦辞+注解（P1 级：彖传象传）
4. 操作区：保存到历史（本地）、再占一卦、（P1 级）生成分享图
5. 页脚：免责声明一行小字 + 详情链接

只读态（从历史进入）：隐藏「保存」，其余一致。

### P5 历史记录页
列表项：占问事项（空则显示「未填写」）+ 本卦→变卦名 + 起卦时间。左滑删除（带确认）。本地存储为空时给引导空态「还没有占卜记录，去起一卦」。

### P6 关于与免责声明页
静态文案页，免责声明全文（按产品文档 6.3），数据存储说明（仅存本机），版本号。

## 4. 手势起卦交互规范（甲方指定需求）

### 4.1 三层手势方案
| 层级 | 手势 | 适用条件 | 体验 |
|---|---|---|---|
| 主 | 摇晃手机（DeviceMotion） | 用户授权 + HTTPS + 移动设备 | 最强仪式感：握住手机摇晃，加速度超过阈值持续≥0.8s 触发掷出 |
| 辅 | 长按铜钱区蓄力→上滑甩出 | 所有触屏设备，无需授权 | 长按时铜钱开始抖动+蓄力光晕渐强（上限2s），上滑释放即掷出；只长按后松手（不滑）= 取消 |
| 兜底 | 「点击摇卦」按钮 | 一切环境含桌面端 | 点击即掷 |

三层同时可用，不互斥；桌面端隐藏摇晃引导，仅显示长按（鼠标按住）与点击。

### 4.2 摇晃权限流程（iOS 要点）
- 进入 P2 首爻前不弹系统权限。引导文案区显示「开启摇一摇起卦」开关，用户点击该开关（一次用户手势）→ 触发系统授权弹窗
- 授权成功：引导文案变为「摇动手机，掷出铜钱」
- 拒绝/不支持：开关消失，引导文案显示长按手势教学动图，不再重复请求授权
- 授权状态在本次会话内记忆，不在每爻重复询问

### 4.3 手势参数（给开发的初始值，测试阶段可调）
- 摇晃触发：加速度变化阈值 15 m/s²，持续 800ms；触发后 1.5s 冷却防止一次摇晃连掷两爻
- 长按蓄力：≥300ms 进入蓄力态；上滑位移 ≥60px 释放视为掷出
- 掷出动效时长 0.8–1.2s，期间忽略一切手势输入（防连击）

### 4.4 关键防错
- 任何手势的随机结果一律来自密码学随机数（产品文档 6.2），蓄力时长/摇晃力度【不得】影响概率分布——仪式感是表演层，公平性是数据层，两者必须解耦
- 同一爻只允许一次有效掷出，结果落定前禁用所有触发入口

### 4.5 反馈通道
- 视觉：铜钱 3D 翻转下落、落定弹跳；动爻额外朱砂标记
- 触觉：掷出与落定时短震动（Vibration API；iOS 网页不支持震动，自动跳过，不做提示）
- 听觉：铜钱碰撞音效，默认静音，提供一键开关（移动端网页自动播放限制：首次开启必须由用户点击触发）

## 5. 全局交互规则

- 加载与计算：排盘计算若 >300ms 显示水墨涟漪 loading；失败给出重试，不丢失已摇六爻数据
- 弱网/离线：起卦与排盘核心流程应可在弱网完成（具体由架构师决定前端计算或缓存策略，此为体验要求）
- 横屏：不专门适配，提示「请竖屏使用」
- 无障碍底线：爻象不只用颜色区分动静（动爻必须有文字/符号标记）；所有可交互元素点击热区 ≥44px

## 6. 移交架构师的待决策项
1. 排盘逻辑放前端还是后端（影响 P2→P4 跳转与离线能力）
2. 本地历史的存储方案与容量上限（建议上限 200 条，超出滚动删除最旧并提示）
3. 分享图生成（P1 级功能）前端 canvas 还是后端渲染

## 7. UX 验收清单（并入测试用例）
- iOS Safari 拒绝传感器授权后，长按与点击路径完整可用
- 连续快速摇晃 10 次只产生一爻结果（冷却有效）
- 375px 宽度卦盘表格无横向滚动（用六神+六亲+纳甲最长组合「腾蛇 父母庚戌土」验证）
- 摇卦中途锁屏/切后台再回来，进度不丢失
